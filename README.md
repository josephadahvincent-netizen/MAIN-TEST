# DEV_ADAH Portfolio

This repository contains a personal portfolio website built with HTML and CSS. It showcases the developer’s background, skills, projects, and contact information in a clean and responsive layout.

## Features

- Responsive landing page with a polished hero section
- About me and skills overview
- Project showcase with links to completed work
- Contact section with a simple form layout
- Mobile-friendly navigation with a hamburger menu

## Project Structure

- index.html — main homepage
- about.html — about page
- contact.html — contact page
- projects.html — projects overview
- style.css — main styling for the site
- projects/ — folder containing individual project demos
- background/ — images and assets used throughout the site
